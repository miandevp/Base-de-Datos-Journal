# Syntactic Optimization

Proceso mediante el cual una consulta es transformada utilizando reglas algebraicas equivalentes con el objetivo de reducir el trabajo que deberá realizar el sistema durante la ejecución.

A diferencia de la optimización física, en esta etapa no se decide qué índices utilizar ni qué algoritmos ejecutar. Solamente se modifica la representación lógica de la consulta para obtener una forma equivalente más eficiente.

## Objetivos

* Convertir consultas SQL en expresiones de Álgebra Relacional.
* Construir árboles de consulta (Query Trees).
* Aplicar reglas de equivalencia.
* Obtener árboles lógicos optimizados.
